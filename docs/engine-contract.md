# Engine Contract

The engine is the source of truth for operations that mutate PDF structure.
The browser editor can preview edits, but engine output decides whether a
feature is real.

## Payload

```json
{
  "pdfBase64": "<source bytes>",
  "password": "<optional password>",
  "pages": [{ "sourceIndex": 0, "rotation": 0 }],
  "operations": [],
  "metadata": {},
  "saveOptions": {
    "annotationMode": "flatten",
    "redactionMode": "textOnly",
    "flattenForms": false,
    "sanitize": false,
    "sanitizeOptions": {
      "metadata": true,
      "xmlMetadata": true,
      "embeddedFiles": true,
      "javascript": true,
      "links": true,
      "thumbnails": true,
      "resetFormFields": false
    },
    "validate": true
  }
}
```

## Engine-Required Operations

- Existing text replacement.
- Redaction.
- Native annotation export.
- Password-backed PDFs.
- Existing annotation delete/replace.
- AcroForm field fill and flatten.
- Existing annotation flatten when `annotationMode` is `flatten`.
- Semantic text reflow generated by the browser layout model.
- Hidden-info sanitization when `saveOptions.sanitize` is true.
- Preflight reporting through `/api/pdf/preflight` or `pdf_engine.py preflight`.
- Future signatures, OCR, full accessibility, PDF/A/X preflight fixups, and
  compare/batch operations.

## Semantic Reflow Operations

The browser owns layout solving and sends concrete operations to the engine.
For moved source text, the payload contains searchable `text` operations. If a
block moves within the same page, the operation includes `eraseOriginal`. If a
block crosses pages, the original page gets a destructive `redact` operation
and the target page gets a separate searchable `text` operation.

The engine must not rasterize text reflow. `flowSlice` remains reserved for
future non-text visual object movement and is not the primary text reflow path.

## Sanitization Options

The current sanitizer removes the hidden data categories exposed through
`sanitizeOptions`: metadata, XMP metadata, embedded files, JavaScript/actions,
links/actions, thumbnails, and optionally stored form values. It also removes
catalog-level `/OpenAction`, `/AA`, and `/Names` entries when present.

Sanitization must preserve visible page content unless a redaction operation
explicitly removes it. Full Acrobat-class sanitization still requires deeper
coverage for hidden layers, comments, embedded search indexes, stale
incremental-save history, and unreferenced object data.

## Validation Response

The engine validation response must include:

- `ok`
- `pageCount`
- `encrypted`
- `annotationCount`
- `textLength`
- `pageSizes`
- `qpdfChecked`
- `errors`

When `REQUIRE_QPDF=1`, `qpdfChecked` must be true and qpdf failures are fatal.

## Preflight Response

`/api/pdf/preflight` and `pdf_engine.py preflight` return a JSON object with:

- `validation`
- `warnings`
- `pageCount`
- `metadata`
- `xmpLength`
- `embeddedFileCount`
- `javascriptActionCount`
- `formFieldCount`
- `fontCount`
- `fonts`
- `pages`

Each page entry includes page boxes, image/drawing/annotation/widget counts,
and font names. This is a basic product preflight, not a PDF/A or PDF/X
certification engine.
